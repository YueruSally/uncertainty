S9–S11：冻结现有单模型，直接评价新大实例

范围
  S9、S10、S11 各 3 个新实例，每实例 3 个共同算法种子。
  每个实例为 50 批货，时间窗系数分别为 0.5、1、2。
  四个方法：Base、Simple（C_RULE，仅交叉规则）、共享监督、PPO u1。
  共 108 次搜索，每种方法 27 次；每配置每方法 9 次。
  pop250，累计目标评价上限 B5000；400、1000、5000 是同一次搜索的记录点。
  每实例固定 100 个 CCP 情景，所有方法和算法种子共用，置信水平 0.9。
  不是用 400/1000/5000 个随机实现重新评价固定前沿。
  由于交叉成对评价，实际搜索可能在 4999 次停止；记录实际计数。

冻结与泛化含义
  复制已完成第二实例实验中共享监督和 PPO 的单成员权重，校验内容哈希。
  共享监督成员为训练种子 991001，PPO 使用现有 u1 的 member_0。
  门控、缩放器、模型结构、进度特征 /50000、M 从第 10 代启用均保持不变。
  不训练、不更换成员、不重新挑选检查点、不应用离线审查的新阈值建议。
  该入口复用已有搜索引擎，不修改任何历史程序或结果。
  原有 S0–S8 结果不并入本次 S9–S11 的均值。
  同一运输网络和原训练 OD 池上生成新的 50 批货实例，保持原数量/释放时间分布；
  排除已有实例的完整批次集合，清单在任何新搜索前冻结，不根据结果重新抽样。
  因之前曾检查 S11，不宣称 S11 配置从未被开发过程接触；本次批次集合是新的。
  如之后修改模型，应作为另一版本报告，不能利用这些结果反复选择最佳模型后仍称独立测试。

运行（在 expanda 目录）
  bash single_s9_s11_b5000_v1/run.sh --workers 2

默认来源
  transformer_ppo_runs/diagnostics/ccp_icm_single_member_second_instance_b5000_v1
默认输出
  transformer_ppo_runs/diagnostics/ccp_single_s9_s11_b5000_v1
可选参数
  --source PATH  --out PATH  --workers 1|2  --prepare-only

  中断后重复相同命令，已完成且通过校验的搜索直接复用。
  运行期间不要修改冻结的模型和搜索代码。

监测
  STATUS.json：总进度、正在运行的实例/方法/种子、子任务日志。
  COST_ESTIMATE.json：四类方法都有完成耗时后，按实际耗时估算剩余时间。
  首个实例的全部 3 种子 × 4 方法完成后生成 preview/results_union/RESULTS.csv。
  预览只描述已完成实例，不按预览效果停止或改变实验。

最终结果
  results_union/RESULTS.csv：三个节点的绝对 HV、相对 Base 平均配对提升、95% 区间、
    W/T/L，5000 节点另列平均搜索时间、标准差、累计搜索时间及推理时间。
  results_union/PER_CONFIGURATION.csv：S9、S10、S11 分开汇总。
  results_union/PER_RUN.csv：每实例、每种子、每节点的配对明细。
  results_union/PPO_vs_SHARED.csv：PPO 直接对共享监督（与相对 Base 的主表分开）。
  results_union/DEPLOYMENT_COSTS.csv：逐次耗时、内存、规则替换和输入截断统计。
  results_frozen/：同一前沿按冻结训练边界计算的结果，供对照。
  fronts/FINAL_SOLUTIONS.jsonl.gz：各次运行的最终解与原始目标值。
  runs/...：完整运行记录和各预算节点前沿，ENVIRONMENT.json 为实际运行环境。

HV 与统计口径
  同实例的四方法、三个种子、三个节点共同确定一套 min/max；参考点 (1.1,1.1,1.1)。
  报告实际三维 HV，不除以 1.331，所以 HV 可以超过 1。
  冻结训练归一化另列，不能混用两个报告的 HV。
  提升逐对计算，再按实例和配置等权平均；不是最大值对 Base 平均值。
  95% 区间在每个固定配置内重抽实例、再抽种子，3000 次配对 bootstrap。
  W/T/L 按 HV 差 >1e-12、绝对差 <=1e-12、差 <-1e-12；Base 自比显示“—”。
  每配置只有三个新实例，区间仍为小规模证据；不保证每次搜索均胜过 Base。

训练及独立重评估
  本入口新增训练/标签评价均为 0，也不进行独立情景重评估。
  若论文另需未见随机实现上的 CCP 稳健性，需要单独设计固定前沿的重评估。
