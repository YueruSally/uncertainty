共享监督消融 v2：只重跑随机组 54 次
=================================

运行：bash shared_sl_ablations_b5000_v2/run.sh --workers 2
只核对与备份：加 --prepare-only。只重算报告：加 --report-only（要求已有54次v2运行）。
重复命令复用完整运行；不会把v1随机组当作v2。停止只终止本次启动的子进程。

输入：已完成的 ccp_shared_sl_ablations_b5000_v1 与 ccp_single_ppo_s0_s8_b5000_v1。
输出：新目录 ccp_shared_sl_ablations_b5000_v2。旧目录不写入。
开跑前将旧报告、RUN_COMPLETE（含三个节点的原始前沿）、模型和代码归档到
backup/OLD_RESULTS.tar.gz，MANIFEST.json保存文件哈希。结束后再次核对源文件。

随机策略
--------
每个组件的目标为全部选择调用中的替换比例：I=.981，C=.433，M=.329。
保留规则候选位置0；只从legal_mask中有效、非零的位置等概率抽取。
第t次调用前已替换S次，有合法替代时条件概率为 clip(r*t-S,0,1)；否则概率0。
这将无合法候选留下的计数差额带到之后的合法决策。仅使用调用数/替换数及合法掩码，
不使用分数、标签、HV或最终结果。每次运行/每个组件使用独立固定随机流。
这是自适应频率控制，不是固定概率的独立Bernoulli，亦不是对每个状态匹配学习门控。
有限样本和终末无合法候选可能留下差额，因此不保证精确相等；报告实际率、与目标及
共享监督原实际率的差异、合法率上限、每次运行计数，不补造或隐藏未匹配的结果。
校准不增加搜索；不按HV调参、换种子或挑选运行。所有运行消耗同一5000评价预算。

复用与归一化
------------
S0–S8每配置2实例×3共同种子，共54对；pop250/CCP100/置信水平.9/K8保持不变。
Base、I/C/M启发式和Transformer、规则ICM、独立ICM、共享监督均复用原运行。
PPO采用最新S0–S8微调流程SELECTION.json指向的完整54次开发部署，若选u0则使用
有明确REUSE_U0记录的共享监督别名。旧PPO前沿不参与新联合边界。
阈值零组复用v1的54次；并检查三个门控启用且阈值均为0，保留规则分数0。
新随机54次+复用648行=13方法×54=702行。物理复用数如有u0别名可少于报告行数。

每实例合并这13种方法、所有种子、400/1000/5000三个节点的全部原始前沿求min/max。
不先全局筛除支配点；参考点(1.1,1.1,1.1)，HV除以1.331。运行时间直接读原记录。
归一化改变可能改变旧方法的百分比、胜负；不修改搜索、训练奖励或原结果。

统计
----
逐实例/种子/节点计算100*(HV方法-HV参照)/HV参照，再实例内平均种子，配置内平均
两个实例，最后九配置等权。不是两个总均值之比。参照为零时停止，不丢弃该对。
95%区间：50,000次在每个固定实例内有放回重抽三个配对种子，方法共享重抽索引；
每次按相同层级平均，取2.5/97.5百分位。固定随机种子20261123。
遵循本次要求，不重抽实例或配置；和旧3000次“重抽实例再抽种子”的区间不同。
这描述固定18个开发实例上的种子不确定性，不是独立新实例泛化证据。
W/T/L使用原HV差的1e-12容差（除盒体积后1e-12/1.331），Base对自己显示破折号。
