共享监督 ICM 单模型消融 v1
========================

固定 seed_991001_epoch_20 单模型，使用已有 S0–S8 的18个开发实例，每实例3个种子。
pop250、B5000、CCP100、0.9分位、K8候选位置、M第10代启用等均不改变。
不训练，不重选模型，不修改既有模型、结果或阈值文件。

两个新增方法，各54次，共108次搜索：

1. ICM_RANDOM_MATCHED：从原54次共享监督运行的 selection 计数冻结各组件概率。
   I=4661/4752、C=27032/62404、M=7189/21875。每次选择以该概率尝试替换；
   只在合法非规则位置中均匀抽取，不调用神经网络。没有合法替代时保留规则。
   每个实例/种子/组件有独立固定随机流，不推进主搜索的随机流。
   匹配的是设定概率，不保证实际比例相等；报告目标与实际比例、没有合法替代的次数。
   这控制总体干预频率，不控制逐状态的干预时机，不能声称只隔离候选排序的贡献。
2. ICM_SHARED_ZERO_THRESHOLD：同一权重、特征、掩码和评分代码，只在内存中把三个
   threshold_scaled 设为0。规则分数保持0，所有合法替代得分<=0时仍保留规则。
   当前基线阈值 I=.05、C=0、M=0，因此只直接移除I的正阈值，不是强制改选。

随机概率使用开发集上的既有决策统计，不读取新消融的HV选概率、不重抽种子。
本实验属于开发诊断。随机与学习结果接近只说明未观察到明确额外收益，不证明等价。

运行（41，expanda目录）：
  bash shared_sl_ablations_b5000_v1/run.sh --workers 2
可先 --prepare-only 核对来源，不启动搜索。重复命令支持复用已完成任务。
中断仅停止本次启动的子进程；既有PPO和其他实验不会被停止。

来源默认 ccp_single_ppo_s0_s8_b5000_v1/PLAN.json 中的 source_records。
Base、规则ICM、共享监督各54次直接复用（162次）；另8种历史方法只保留原始前沿，
用于延续原11方法的归一化池。108次新搜索均另存。

每完成一个配置（两个实例、三个种子、两个消融，共12次）生成preview报告。
全部完成后 results/ 包含：
- RESULTS.csv：五个方法，400/1000/5000节点，均相对Base。
- DIRECT_COMPARISONS.csv：共享监督−随机；共享监督−阈值零；随机−规则；阈值零−规则。
- PER_CONFIGURATION.csv、PER_PAIR.csv：逐配置及逐次配对数据。
- REPLACEMENT_RATES.csv：各组件实际替换率，随机目标概率和无合法替代次数。
- INSTANCE_BOUNDS.json、REPORT.json：共同归一化边界及统计定义。

HV按同实例所有历史11方法+两个新方法、全部种子、全部节点的目标点确定共同边界，
参考点(1.1,1.1,1.1)，报告HV和HV差均除以1.331；不要再次除。
重新汇总可能改变旧方法的HV和相对提升，原搜索结果和原表保留不变。
95%区间沿用原分层配对bootstrap：配置等权，配置内抽实例，再抽种子，3000次。
W/T/L容差为原HV的1e-12（除体积后为1e-12/1.331），三个节点都报告。
节点累计耗时、B5000完整搜索耗时分开报告。随机组候选选择耗时不含神经网络前向，
但保留原控制器的候选和特征构建成本。控制组复用历史计时，应说明机器负载的影响。

FROZEN_DECISIONS.json记录原始计数、目标概率、原门控与改动范围。
PLAN.json记录所有复用文件和运行代码的哈希。任一不一致均停止，不自动改源数据。
