完整预算比较的只读诊断

在 expanda 下运行：
python3 -u audit_multiscale_screen_v1/audit.py

默认读取 ccp_icm_multiscale_joint_v1 下108次不同策略的原始结果，
以及 ccp_icm_multiscale_joint_v1_unique_resume_v2/results 的最终报告。
新建同级 ccp_icm_multiscale_joint_v1_screen_audit_v1；不覆盖已有输出。
可用 --source、--report、--out 指定其他路径。

不重新训练、不调用目标评价函数、不启动搜索、不改权重、门控、原始结果或主分析指标。
仅用Python标准库，无需安装软件。读取数据失败或不一致时直接报错，不能将失败解释为审核通过。

检查：
1. 运行网格、实例/情景配对、预算、冻结检查点、训练/验证/比较集名称分离。
2. 原始最终前沿与保存的目标名称顺序一致；独立实现的三维HV复算。
3. 逐实例所有方法/种子的共同min/max与原表HV、配对均值一致。
4. 同时报告训练归一化下的结果；只是尺度敏感性诊断，不根据结果选择归一化。
5. 输出实际学习调用、回退、改选和特征截断比例；缺失量不填成已证明为零。
6. 输出各预算点在固定训练归一化下的配对差，识别早期收益与后期变化。

最大值的定义：对每个实例、每种方法，在相同的三个预定种子中取最大HV，
与Base或启发式各自同样三次中的最大HV比较。所有运行仍保留。
这是事后补充的best-of-three多次启动结果，上限为3×50000次评价，
总时间计三次之和，不能替换单次B50000配对均值，也不是新的独立验证证据。
不允许跨配置选一个最大值，也不允许学习最大值与Base均值比较。

主要文件：
PAIRED_MEAN_CHECK.csv：两种归一化下的配对均值及胜平负。
BEST_OF_SEEDS_PER_INSTANCE.csv / BEST_OF_SEEDS_SUMMARY.csv：相同重启次数下的最好值。
EXECUTION.csv：学习执行与输入截断。
CONVERGENCE_PAIRED.csv：同一训练归一化下，各预算点的配对变化。
RUN_CHECK.csv：逐次预算、代数、可行率、缓存与成本。
MODEL_SUMMARY.json：实际模型数据量、门控、损失和选轮依据。
SUMMARY.json / INPUT_HASHES.json：检查结论与读入文件哈希。

代码审阅已确认（不是因果结论）：
- I保留容量/贪心种子，只改变随机初始化部分。
- C/M反馈来自Base轨迹，联合部署遇到的种群分布可能不同。
- C用Base变异后的完整子代构造特征与单步标签；联合部署先选交叉，后由M独立修改。
- M第10代起在Replace候选池内选择，而不是重新选择全部Base变异操作。
- 监督损失是合法候选对按收益差幅度加权的softplus排序；门控按验证单步收益选择。
这些差异值得解释和验证，但不单独证明过拟合、数据不足或某一组件造成全部性能下降。
