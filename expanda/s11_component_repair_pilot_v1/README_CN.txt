SOURCE.json 记录旧冻结清单哈希和 C 的逐文件哈希，便于回退和审计。

共同设置
S11：50批货，pop250，B50000，固定CCP100，q90，K8。
预算包括初始化和可行性增强；有效未改变缓存不重复计数，两个新子代按两次计。
2个全新开发筛选实例 × 1个共同算法种子982001 × 7组方法 = 14次完整搜索。
方法：Base、I_RULE/I_LEARN、C_RULE/C_LEARN、M_RULE/M_LEARN。
原始物理评价、目标、可行性定义和修复函数均不更改。

I 的修改
保留 Base 前162个容量种子/贪心种子；只改变剩余88个随机位置。
K8仍包含原始Base候选，另7个候选用现成的计划资源表做容量协调。
表同时含运输腿和口岸时段资源，按原分配份额缩放各条路径资源用量。
每候选最多2次重启、32步；不调用目标函数或额外情景模拟。
原份额保留，仅按已有修复规则合并重复路径；不新增强制路径数限制。
规则候选是经过同样协调的Directed，学习与规则共享候选构造。
名义超量为0不作为真实可行性的替代，实际可行性仍由原评价函数判断。
4训练/2验证实例各采48个前、中、后初始化位置，只运行初始化。
先检查训练候选：至少2个训练实例存在真实正残差机会，才继续完整M采集。
验证标签不用于这个准入条件，不按结果重新抽实例；不通过就停止并输出原因。

M 的修改
使用预先固定的GUARDED规则：原Balanced若在确定性代理的缺失、容量、迟到
或目标上明显劣于同次Base变异候选，就回退到Base候选。代理保护不是HV保证。
此规则与学习版共用，沿各自M规则轨迹采集，仍从第10代启用。
4训练/2验证实例各走一条完整轨迹，每条稀疏标注96个状态，覆盖早、中、晚期。
保留所有状态以及正、负、零残差。各训练小批次同时有非零标签和打平状态时，
损失按0.75/0.25组合，两部分内部仍使用原排序损失+0.5 SmoothL1。
非零组包括只有负残差的状态，不只保留正收益案例；验证不使用这种加权。

C 的处理
逐字节复用上一轮 C 的3个已选权重、归一化、特征缩放及门控。
保持GUARDED规则和原候选构造。无C重训、无C标签采集，只在新实例上复核。

训练与统计
I/M各训练3个种子，30轮，原10/20/30轮检查点和门控网格；允许全规则回退。
原始候选及参考目标 → 训练实例拟合HV界限 → 构造归一化种群统计与残差标签
→ 训练实例拟合输入标准化/标签尺度 → 训练与验证；筛选实例不参与拟合。
I/M的公共HV界限用新训练轨迹及新训练候选拟合；C继续用原模型自带界限。
最终报告对每个实例汇总全部7组方法的最终可行前沿确定公共min/max，参考点1.1。
同时保留训练归一化下的结果。不按哪种口径更好来切换主指标。
本轮规则和I/M训练过程有变，不能把旧实例结果混入本轮配对统计。
2实例×1种子仅为方向性小试，区间为探索性描述，不能证明稳定优越。
