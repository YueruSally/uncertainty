固定方案的 CCP 90% 分位精度检查 v1

本程序不搜索、不训练，不加载模型推理，不修改任何已有实验文件。
只复用 Base 和当前单模型 Shared SL（991001，第20轮）已保存的方案。
模型文件只用于校验身份。没有新 PPO，也没有改动正在进行的 S9–S11 搜索。

固定协议
1. S0–S8：原54对实验中的 joint-confirm-Sx-001，各3种子。
2. S9–S11：single-large-Sx-001，各3种子。
3. 每实例合并 Base/Shared 的6个最终B5000前沿，按完整决策去重。
   所有方案保留，不按性能或误差挑选。共12个实例、72份已有前沿。
4. S0优先。每实例先用原100情景重算目标，检查情景哈希和逐方案目标。
   原100生成100个；不能拿1000集合的前100个冒充原抽样。
5. 原结果复现通过后，独立抽1000个实现作为有限样本参考，另抽20组100。
   每实例所有固定方案共用每组情景。不同组种子不同，不使用搜索种子。
   q90为排序后第ceil(0.9*N)个样本；三个目标分别计算，不是联合90%保证。
6. 新目标原始单位保存。此项主指标是分位误差/波动/目标内排序，未重新计算HV，
   也未修改主实验HV归一化或参考点。参考1000不是“真值”。

资源和恢复
单进程、数值库单线程、nice=10（仅降低本程序优先级）。会使用一个CPU核的
空闲时间，不能保证完全无资源争用；不停止、不抢占其他程序的任务或输出目录。
若固定编号001的Base/Shared尚未完整结束，状态为waiting_for_source，每30秒
只读检查一次，不启动补跑。可用--no-wait退出，稍后重复同一命令恢复。
每完成一组情景即保存压缩数组和校验记录。中断后重复命令复用完整组；
未完成的一组重算。勿改变文件后覆盖原输出，需新版本目录。
--s0-only只做S0，之后去掉此参数在同目录接续。默认S0通过后自动覆盖12配置。

在expanda目录运行
nohup bash fixed_q90_s0_s11_v1/run.sh >> transformer_ppo_runs/diagnostics/ccp_fixed_q90_s0_s11_v1/pipeline.nohup.log 2>&1 < /dev/null &
启动前须mkdir -p该独立输出目录。已有运行时锁会阻止重复启动本检查。
依赖沿用现有Python：numpy、pandas、openpyxl、matplotlib；无需新增scipy。

输出（CSV统一UTF-8 BOM）
STATUS.json：当前配置、情景组、已评价方案数或等待文件。
SOURCE_INVENTORY.json：固定来源是否齐全、各配置去重方案数。
S0/REPRODUCTION.json：原100目标复现误差；失败则停止，不做新抽样。
S0/SUMMARY.csv：首批误差/排序/波动，S0完成即可查看。
SUMMARY.csv：逐配置×三个目标，每配置完成即追加汇总，不等12个配置。
CONFIGURATION_EQUAL_SUMMARY.csv：配置等权汇总，含当前完成配置数。
每配置/PER_PLAN_QUANTILES.csv：每个方案原100、参考1000、20组100分位及波动。
每配置/REPLICATE_METRICS.csv：20组误差与Spearman，均在同一配置/目标内比较。
每配置/REPRESENTATIVE_DISTRIBUTIONS.png/pdf：预先按最小决策哈希固定的方案；
  第1组新100与参考1000，直方图密度和经验CDF，坐标是原始单位。
每配置/REPRESENTATIVE_KS.csv：999次置换双侧KS，保留重复数值，辅助结果。
每配置/FEASIBILITY.csv：新情景下可行/不可行计数，不静默删方案。
每配置/SOURCE_MEMBERSHIP.csv：方案属于哪个方法/搜索种子，便于追溯。
每配置/packs/*.npz：全部原始实现下的目标值、q90、可行性与违反度。
COSTS.json：完成组的固定方案评价数、方案×实现次数、评价耗时。
  physical_*_including_retries字段来自逐次评价账本，包含中断组重做的评价。
  evaluator_seconds为完成组的时间；中断的未完成组耗时未计入该字段。
ETA.json：S0后按实际耗时和批次数估算剩余计算时间，不含等源文件时间。
REPORT.md：英文简报与必要限制。

解释限制
1000只是更精细的独立参考，附其q90的逐方案95%次序统计量区间。
原100参与过优化选择，不能代替独立20组稳定性证据。
Spearman分别按成本/排放/时间计算，不能冒充多目标Pareto排序一致率。
常数向量的相关系数为空；参考q90为0时相对误差为空并报告数量。
共同实现使方案误差相关；不把全部方案/20组当独立搜索样本做显著性检验。
不显著的KS结果不证明分布相同，更不自动证明100个实现足够。
每配置仅1个实例，是覆盖12配置的精度诊断，不证明全部实例和分布都适用。
S9–S11仅检验已冻结评价协议，不根据其结果选模型、重训或自动改实现数。
