6.2 全部固定方案的 P90 秩相关与两样本 K–S 汇总

运行（expanda 目录内）：
  python3 -B -u fixed_q90_rank_ks_v1.py

输入：transformer_ppo_runs/diagnostics/ccp_fixed_q90_s0_s11_v1
输出：transformer_ppo_runs/diagnostics/ccp_fixed_q90_rank_ks_v1
可用 --source 和 --out 指定目录。输出必须与原结果目录分开。
只读取已完成的12配置抽样包，不调用运输方案评价器，不搜索、不训练、不抽取新的运输情景。
每配置完成后保存统计缓存；中断后重复命令复用已完成配置。
单进程、单线程；系统允许时降低到 nice 10。

统计口径：
1. 保留原6.2在每个配置内按完整方案去重后的全部方案，不按方法、误差或可行性筛选。
2. Spearman 对成本、排放和完成时间分别计算：每组100次的逐方案P90，对独立1000次参考的逐方案P90。
   20组各算一次，再报告平均值、最小值；重复值取平均秩，常数序列的相关系数记为未定义。
   ALL 合并12配置的全部方案，另列每配置结果及配置等权平均，三种汇总口径不混用。
3. K–S 每方案、每目标单独比较第一组新100次与独立1000次的原始目标实现值。
   不是比较两个P90数，不使用优化时的原100次，也不合并20组100次。
   沿用原6.2双侧K–S统计量及999次随机标签置换，保留重复观测值。
   p=(置换统计量不小于观测统计量的次数+1)/1000，严格统计 p>0.05。
   原代表方案使用原置换种子；其他方案的置换种子由配置、方案ID和目标固定生成。
   置换只是对已有样本重新分组，不产生新的运输实现或方案评价。
4. 校验源文件哈希、抽样种子、方案身份和两个原始样本包的P90顺序统计量。
   同时核对原每配置Spearman和代表方案K–S结果；源文件变化或核对失败即停止。

主要输出：
  REPORT.txt：可直接阅读的中文结果。
  SPEARMAN_ALL_PLANS.csv：全部方案合并的20组相关系数平均值、最小值。
  SPEARMAN_BY_CONFIGURATION.csv：12配置×3目标的平均值、最小值。
  SPEARMAN_REPLICATES.csv：总体及每配置的20组逐组结果。
  KS_ALL_PLANS.csv：每目标 p>0.05 的方案数、总数、比例。
  KS_BY_CONFIGURATION.csv：同一比例按配置拆分。
  KS_PER_PLAN.csv：每方案、每目标的统计量、p值和置换种子。
  CONFIGURATION_EQUAL_SUPPLEMENT.csv：配置等权的辅助汇总。
  PLAN_IDENTITIES.csv、PLAN.json、INPUT_HASHES.json、STATUS.json：来源及完成记录。

解释限制：
总体相关可能受配置间规模差异影响，需要同时看配置内结果。
逐目标相关不代表Pareto支配关系完全保持。
1000次参考仍有抽样误差；p>0.05表示未检出差异，不等于证明分布相同或100次充分。
K–S比例未作多重检验校正，仅作为描述性汇总；同实例方案共用情景，检验结果存在相关性。
